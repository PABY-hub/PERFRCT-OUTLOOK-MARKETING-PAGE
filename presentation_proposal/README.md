Presentation & Proposal package

Files included:
- slide_deck.md — lightweight slide deck you can copy into PowerPoint/Google Slides.
- proposal.md — project proposal draft (editable).

How to use:
- Open `proposal.md` to review and edit the proposal text.
- Use `slide_deck.md` as the basis for a slide deck. Copy its headings into PowerPoint or Google Slides.

If you want a PPTX or PDF exported automatically, tell me and I can add a small script or convert the markdown to PDF using a toolchain (requires additional dependencies).
